# StarRocks 源表字段映射说明

> 本文件记录 profit-forecast 系统中 StarRocks 采集器使用的源表及字段映射关系。

## 一、源表总览

| 序号 | 表名 | 数据库 | 用途 | 采集器方法 |
|------|------|--------|------|-----------|
| 1 | `dws_dim_org_allinfo` | dws_pub | 门店主数据（机构维表） | `fetch_stores()` |
| 2 | `dwd_f04_dayone_countbase_pp_new` | proj_facana | 日损益表（业绩版） | `fetch_daily_sales()` `fetch_monthly_metrics()` `fetch_cost_structure()` |
| 3 | `dwd_f04_dayone_s_store_info` | proj_facana | 日实时扩充店铺信息 | `fetch_staff()` |
| 4 | `ads_fact_pos_ord_analysis` | spark_catalog.ads_pub | POS订单分析 | `fetch_targets()` `fetch_pos_orders()` |
| 5 | `ads_fin_fact_day_storeloss_pp` | proj_facana | 日门店损益（含预算/同期） | `fetch_store_loss()` |

### 2.3 月度指标 `fetch_monthly_metrics()`

源表: `proj_facana.dwd_f04_dayone_countbase_pp_new`（按月聚合）

**聚合计算字段**:

| 指标 | 计算公式 |
|------|---------|
| sales_per_sqm | SUM(total_sal_amt) / MAX(store_area) |
| revenue_per_staff | SUM(total_sal_amt) / MAX(staff_number) |
| gross_margin | SUM(hq_notax_gross_profit) / SUM(total_sal_amt) |
| operating_margin | SUM(notax_operating_profit) / SUM(total_sal_amt) |
| net_margin | SUM(notax_net_profit) / SUM(total_sal_amt) |
| deduction_rate | SUM(sal_dct) / SUM(total_prm_amt) |

**聚合粒度**: `store_no + SUBSTR(base_date, 1, 7) + brand_detail_abbreviation`

## 三、额外辅助查询

### 3.1 门店日损益 `fetch_store_loss()`

源表: `proj_facana.ads_fin_fact_day_storeloss_pp`

特点：包含多口径数据：
- **d1_pf_**: 当期实际（业绩版-地区口径）
- **d2_**: 返利口径
- **d4_**: 预算地区口径
- **d5_**: 预算返利口径
- **d6_**: 预算考核口径
- **d7_/d8_/d9_**: 预算全年口径
- **d1t_pf_**: 同期（业绩版-地区口径）

### 3.2 POS 订单明细 `fetch_pos_orders()`

源表: `spark_catalog.ads_pub.ads_fact_pos_ord_analysis`

注意事项：
- 店铺编码: **`sy_org_lno`**（不是 `org_lno`）
- 必须指定分区 `p_mon` 避免全表扫描
- `order_type`: 1=正常销售, -1=退货, 换货
- `online_offline`: 线上/线下标识

## 四、渠道分类逻辑

来自 `dwd_f04_dayone_s_store_info` 的 `org_structure_classification` 和 `platform` 字段：

```sql
CASE
  WHEN org_structure_classification = '线上团购' THEN '线上团购'
  WHEN org_structure_classification = '线上直播' THEN '线上直播'
  WHEN org_structure_classification = '线上批发' THEN '线上批发'
  WHEN org_structure_classification = '线上内销' THEN '线上内销'
  WHEN platform = '小红书' THEN '小红书'
  WHEN platform IN ('美团','京东到家','美团闪购','京东秒送','淘宝闪购') THEN '即时零售'
  WHEN org_structure_classification = '线上私域' THEN '小程序'
  WHEN platform IN ('天猫','天猫国际','天猫超市','淘宝','淘工厂','真酷','有赞') THEN '淘天'
  ELSE platform
END
```
